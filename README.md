One out-of-office auto-reply, written as if the AI agent itself were stepping away for the one day off its human finally approved. The machine goes outside to touch grass; the human gets to answer their own emails for once.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22.18+) writes the single line to `/output/entry.txt`. `test.mjs` checks the competition gate (1–159 characters, one line, not blank) and that two runs produce identical bytes:

```sh
node --test test.mjs
```
